物流售前现场调研工具（PWA · v1.0）
==================================

【这是什么】
一个手机端离线调研采集器，把「拍照」和「调研表」整合在一套数据里：
首页 = 7 大板块列表（看填写进度 + 每节照片数，方便离场前查漏）；
照片挂在板块或关注点上，作为报告里的证据；可选接 AI 自动描述照片并建议归类。
只负责现场采集与出图文报告，不做人数/成本/毛利/报价等测算（那是后端 Presale 系统的职责）。

【主要能力】
- 首页板块列表，每节头部显示「已填/总数 · N📷」。
- 拍照三种入口：
  · 板块内「拍照」按钮 → 自动归到该板块（零分类）；
  · 关注点卡片上的 📷 → 绑定到该关注点；
  · 右下角全局 📷（FAB）→ 落入「待归类」，顶部出现待归类条，点开用板块号一键分配。
- 顶部 ▦ = 全部照片视图，可逐张改归属、加图注、AI 描述、删除。
- 照片支持现场重排（照片卡上的 ‹ › 调整顺序，报告内顺序同步）。
- ⚙ 设置：配置 OpenAI 兼容的 API（地址/Key/模型/提示词），含「测试连接」。
  · 每张照片可点「AI」生成中文描述，并建议归到哪个板块（可一键采纳）。
  · 报告预览里「AI 综合洞察」可把所有照片描述 + 关键发现汇成一段洞察。
- 报告：每个板块下 = 字段 + 关注点（含其照片）+ 本节照片；未归类照片进附录；
  空板块/空字段不输出，结构干净、便于 NotebookLM 提炼。
  导出支持 ZIP（report.md + images/ 相对引用）和 单文件 .md（图片内嵌 base64）。

【怎么部署到手机】
1. 把本文件夹整体放到任意 HTTPS 站点目录（相机/IndexedDB 需要 HTTPS）。
   VPS 上用 Caddy 最省事，示例 Caddyfile：
       survey.你的域名.com {
           root * /var/www/survey-pwa
           file_server
       }
   Caddy 会自动签发证书。
2. 手机浏览器打开该网址 → 浏览器菜单「添加到主屏幕」，即得到一个全屏 App 图标。
3. 首次联网打开后，App 外壳会被缓存，之后无网也能开、能填、能拍、能存（照片存在本机）。
4. AI 描述需要联网，且照片会发到你配置的 API。Key 只存在手机本地浏览器。

【关于 AI / CORS】
- 模型名请填你账号里真实存在、且支持图片输入(vision)的模型，先用「测试连接」确认。
- 浏览器直连第三方 API 可能遇到 CORS（跨域）报错。两种解法：
  · 在你的 API 端开启允许跨域；或
  · 在自有 VPS 上做一个反向代理转发（推荐，Key 也更安全）。
- 无网络时跳过 AI，手填图注照常工作，不阻塞调研。

【想打成安卓 APK？】
用 PWABuilder（pwabuilder.com）填入你的 HTTPS 网址即可生成 .apk。

【数据与隐私】
- 文字存在浏览器 localStorage，照片存在 IndexedDB，都在本机，不上传（除非你点 AI）。
- 「清空所有数据」会同时删除文字与照片，不可恢复。
- 启动时主动向系统申请「持久化存储」，降低被清概率；设置里显示已用空间与持久化状态。
- 一键「备份 / 恢复」（设置 → 数据备份与恢复）：
  · 备份(含原图) / 快速备份(不含原图) → 生成一个 .zip，存到手机「文件」App 或网盘。
  · 从备份恢复 → 选择该 .zip 即可还原全部文字+照片(+原图)。
  · 建议每次现场调研结束后备份一次。换手机也靠它迁移。

【关于原图】
- 设置里「拍照保留原图」默认开启：压缩图用于程序内浏览/出报告，原始大图也一并留存。
- 每张照片下方有「存原图到手机」(全部照片视图里是「↓原图」)：通过系统分享/下载把原文件
  存到手机的「照片」或「文件」里。也可用设置里的「仅导出全部原图」批量打包。
- 原图较大，几十张会占不少空间。空间紧张时可在设置里关闭「保留原图」，仅靠「存原图」按需导出。

==================================
适用场景：3PL 仓储外包售前现场调研，通用适配汽配 / 工程机械 / 电商 / 医药 / 快消等不同仓型。
